# CLAUDE.md - TG-LiteNet v2 (CSD361 final project)

Retinal vessel segmentation study: compact, topology-aware, source-only model (DRIVE -> STARE / CHASE_DB1 / HRF, FIVES extra).
Read `README.md` and `protocol/PROTOCOL.md` first. v1 is archived in the git tag `v1-final` (reference only).

## Rules for this repo
* **Do not add Claude/AI as co-author or attribution trailers to commits or PR descriptions** (team instruction).
* v2 work lives on the branch `v2-rebuild`; never commit to `main` or push without being asked.
* **Never fabricate or hand-edit results.** Everything in `results/` is generated by `src/tglite/report.py` from `runs/`.
* Protocol invariants (see protocol/PROTOCOL.md): train on DRIVE-train only; DRIVE-val is the only data for checkpoint
  selection, budget, backbone choice, threshold / fragment size / temperature; STARE, CHASE_DB1, HRF, FIVES are test-only
  and can only be evaluated after `protocol/decisions.json` has `frozen: true`. Headline threshold is 0.5 (mode `raw`);
  `clean` / `tuned` modes use DRIVE-val choices. All stages share optimiser, schedule, 16 views/step and data pipeline.
* Never edit `protocol/PROTOCOL.md`, `configs/*.yaml` after the freeze without recording it as a deviation.
* Smoke tests write only to `runs_smoke/`; nothing fake goes into `runs/` or `results/`.
* Not committed: `data/*` (except data/README.md), `runs/`, `runs_smoke/`, `.venv/`, `*.pt`.

## Conventions
* All hyper-parameters in `configs/base.yaml`; every run is an entry in `configs/experiments.yaml` (add new runs there).
* Metrics inside the FOV against NATIVE-resolution labels (model runs at the 540-px-FOV scale, probabilities resampled).
  Topology: 8-connectivity, beta1 = beta0 - Euler number.
* Code must stay device-agnostic (tests run on CPU). Python 3.12 + PyTorch 2.11 (CUDA 12.8).
